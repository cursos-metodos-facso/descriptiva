Errores de R cuando procesamos una base de datos

En el práctico anterior debían usar las siguientes funciones:

# PASO PREVIO: código para cargar librerias

pacman::p_load(haven, dplyr, car)

# EJERCICIO 1: código para importar datos 

proc_elsoc <- read_sav("../data/ELSOC_W06_v1.0_SPSS.sav")

# EJERCICIO 2: código para seleccionar datos

proc_elsoc <- select(proc_elsoc, m0_edad, c15, g01_01, g01_02, g01_03, g01_04, g01_05)

# EJERCICIO 3:código para recodificar datos 

proc_elsoc$g01_01 <- car::recode(proc_elsoc$g01_01,
                                            recodes = c("1 = 'Totalmente en desacuerdo';
                                                       2 = 'En desacuerdo';
                                                       3 = 'Ni de acuerdo ni en desacuerdo';
                                                       4 = 'De acuerdo';
                                                       5 = ' Totalmente de acuerdo';
                                                       -666 = NA;
                                                       -777 = NA;
                                                       -888 = NA; 
                                                       -999 = NA"))
Nota

Tal como se menciona en la lectura, antes de recodificar debemos explorar los datos. Como queremos ver la estructura de vectores específicos del data.frame, debemos usar el operador $ y la siguientes funciones:

  • table(df$vector)
  • sjmisc::frq(df$vector)

Sin embargo, cuando intentaron recodificar les aparece el siguiente error:

Error in `[<-`:
! Can't convert `value` <character> to <double>.

Esto es algo que ocurre comunmente cuando trabajamos con datos secundarios y con bases de datos en formato .sav, porque:

  • Este formato es para ser utilizado en SPSS, donde las variables que entenderemos como categóricas (y que esperaríamos que se encuentren en clase “character” o en clase “factor”), se importaran como clase númeric. Dado que en SPSS permite asignar etiquetas a los valores númericos.

¿Qué debemos hacer?

Covertira a character:

class(proc_elsoc$g01_01)
[1] "haven_labelled" "vctrs_vctr"     "double"        
proc_elsoc$g01_01 <- as.character(proc_elsoc$g01_01)

class(proc_elsoc$g01_01)
[1] "character"

Y, como se tratan de niveles de acuerdo, luego convertir a factor en la recodificación misma:

proc_elsoc$g01_01 <- car::recode(proc_elsoc$g01_01,
                                            recodes = c("1 = 'Totalmente en desacuerdo';
                                                       2 = 'En desacuerdo';
                                                       3 = 'Ni de acuerdo ni en desacuerdo';
                                                       4 = 'De acuerdo';
                                                       5 = 'Totalmente de acuerdo';
                                                       -666 = NA;
                                                       -777 = NA;
                                                       -888 = NA; 
                                                       -999 = NA"),
                                 as.factor = TRUE,
                                 levels = c("Totalmente en desacuerdo",
                                            "En desacuerdo",
                                            "Ni de acuerdo ni en desacuerdo",
                                            "De acuerdo",
                                            "Totalmente de acuerdo"))

[1] "factor"

Otros errores comunes de R

  1. Error de tipeo en la ruta del archivo (cuando importamos nuestros datos):
proc_elsoc <- read_sav("imput/ELSOC_W06_v1.0_SPSS.sav")
Error: 'imput/ELSOC_W06_v1.0_SPSS.sav' does not exist in current working directory ('C:/Users/LENOVO/Documents/GitHub/descriptiva/assignment').
  1. Error de tipeo en el objeto data.frame que estamos usando:
proc_elsoc <- select(proc_elsoc, m0_edad, c15, g01_01, g01_02, g01_03, g01_04, g01_05)

proc_elsoc <- na.omit(Proc_Elsoc)
Error in eval(expr, envir, enclos): objeto 'Proc_Elsoc' no encontrado
  1. Error de tipeo en la estructura del código que estamos utilizando (por ejemplo, no usar todos los paréntesis necesarios):
proc_elsoc$m0_edad <- car::recode(proc_elsoc$m0_edad, recodes = c("-888 = NA; -999 = NA")
Error: <text>:3:0: unexpected end of input
1: proc_elsoc$m0_edad <- car::recode(proc_elsoc$m0_edad, recodes = c("-888 = NA; -999 = NA")
2: 
  ^
  1. R no encuentra la función que queremos usar (debido a que no cargamos su paquete al inicio de la sesión):
frq(proc_elsoc$c15)
Error in frq(proc_elsoc$c15): no se pudo encontrar la función "frq"

¿Qué no vimos la sesión anterior?

La sesión anterior buscaba que ustedes se familiarizarán con el software y utilizarán el programa de la forma más básica. Ahora, profundizaremos en otros aspectos que pasaron desapercibidos la sesión anterior, pero son muy útiles para su trabajo en R: temáticas de orden.

Orden del Script de R

  • Comentarios en el documento con #

  • Secuencialidad del código

  • Uso de espacios (tecla ENTER) en el documento de R:

    • Si bien el documento de R tiene los números en cada línea es solo para orientarnos en algún error de código, podemos hacer espacios y no ocurre nada malo, solo se ve más ordenado nuestro código.

  • Nombre del objeto: sufijo “proc_”

    • Distinguir entre: sobreescribir y escribir un objeto

  • Seleccion de las variables con select()

    • Orden de selección
    • Renombrar las variables
